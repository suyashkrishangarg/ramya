## 1. brand philosophy & core identity

1. **the lowercase regime:** 
   * `ramya ai` is deliberately stylized in all-lowercase. This represents approachable intelligence, modern engineering discipline, and focused minimalism.
2. **invisible interface:** 
   * UI components should never distract from the user's work. Avoid heavy gradients, skeuomorphic shadows, and noisy decorations.
3. **tactile precision:** 
   * Use razor-thin 1px hairline borders, subtle frosted glassmorphism, and soft ambient glows that highlight key interactive elements.
4. **hybrid visual language:** 
   * Distinct accent colors communicate compute state instantly:
     * **emerald:** on-device execution / 100% free / local privacy.
     * **violet:** cloud mesh / deep multi-step reasoning.
     * **electric cyan:** primary interactive elements and core branding.

## 7. motion & animation principles

* **responsiveness:** Interactive micro-animations (button hovers, card focus) must occur within **150ms** to ensure a snappy, lightweight feel.
* **easing curves:** Use an **exponential ease-out curve** (`ease-out-expo`) rather than linear transitions for smooth deceleration.
* **scroll reveals:** Elements entering the screen use a slight upward drift (8px to 12px) paired with a clean opacity fade.
